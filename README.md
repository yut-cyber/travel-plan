# 🧳 旅行计划表

一个**单文件**旅行计划 + 记账应用：时间轴式行程规划、车票/酒店/花费分类记账、预算跟踪、多人垫付分账，纯前端零依赖，数据保存在本地浏览器。

## ✨ 功能

- **预算总览** — 剩余可用 / 总预算 / 进度条，车票 · 酒店 · 花费三类构成一目了然
- **时间轴行程** — 按天分组的卡片流，每条记录：时间 + 内容 + 类型 + 金额
- **时间点选** — 快捷时段（上午/中午/下午/晚上/全天）或起止时间选择器，不用手打字
- **分类记账** — 车票 🚅 / 酒店 🏨 / 花费 💰 / 行程 📍 四种类型，行程不参与计费
- **谁付的** — 每笔开销标记付款人，自动统计各自垫付总额和未分配金额，旅行结束对账方便
- **卡片排序** — 拖动 ⠿ 手柄调整同一天内的顺序（桌面鼠标 / 手机触屏都支持）
- **就地编辑** — 点哪改哪，回车确认，自动保存
- **备份 / 恢复** — 一键复制 JSON 备份，换浏览器、换电脑、迁移线上版时粘贴恢复
- **导出 / 打印** — 导出为纯文本发给别人，或直接打印纸质版
- **移动端适配** — 防 iOS 聚焦缩放、大触控目标、底部安全区

## 🚀 使用

### 在线版（GitHub Pages）

部署后访问 `https://<你的用户名>.github.io/travel-plan/` 即可使用。

### 本地使用

下载 `index.html`，双击用浏览器打开即可，无需安装任何东西。

## 💾 数据说明

- 所有数据仅保存在**本机浏览器**的 localStorage 中，不上传、无账号、无追踪
- localStorage 按「源（origin）」隔离：本地文件、不同浏览器、线上地址的数据各自独立
- 跨设备 / 跨浏览器迁移：旧页面点「**备份**」复制 JSON → 新页面点「**恢复**」粘贴
- 清除浏览器缓存会丢数据，重要行程建议随手备份一份

## 🔧 技术实现

- 纯原生 HTML / CSS / JavaScript，**单个文件**，无任何框架、依赖、构建步骤
- 内置数据版本迁移链（v1 → v2 → v3 → v4），页面改版后旧数据自动升级，不丢内容
- 触屏拖拽用 Touch 事件单独实现（HTML5 Drag API 在移动端不生效）
- 打印样式独立优化，输出的纸质版隐藏所有交互控件
